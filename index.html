Otomatis Baca Folder: Setiap kali Anda mengupload video baru ke folder Google Drive, website akan otomatis mendeteksi dan memutarnya di dalam frame.

Panduan Singkat Koneksi Folder Google Drive:

  1. Buka Google Drive, klik kanan pada folder video Anda → Bagikan (Share) → Ubah akses menjadi "Siapa saja yang memiliki link" (Anyone with the link).
  2. Salin link folder tersebut dan tempel pada kolom di atas.
  3. Agar website bisa membaca isi folder secara otomatis & memutar video kualitas asli tanpa tombol klik manual, buat API Key gratis di console.cloud.google.com:
    • Buat Project baru → Buka menu APIs & Services → Library.
    • Cari & aktifkan Google Drive API.
    • Buka menu Credentials → Create Credentials → API Key, lalu salin ke kolom di atas.

*Tips: Belum punya API Key? Anda bisa menggunakan tab "Link GDrive" atau "Folder Lokal", atau klik tombol Simulasi Folder GDrive di bawah.

Tanpa API Key: Tempel satu atau beberapa link bagikan video Google Drive (drive.google.com/file/d/...) atau link langsung .mp4 (satu link per baris).
Tips Google Drive Desktop / Lokal: Jika Anda menginstal aplikasi Google Drive for Desktop di laptop/PC, Anda bisa memilih langsung folder Google Drive tersebut di bawah ini tanpa perlu internet/API Key!
